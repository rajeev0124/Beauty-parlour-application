```bash

# Step 2: Build frontend  
cd beauty-parlour && npm run build && cd ..

# Step 3: Deploy backend (auto-deploys on push)

# Step 4: Deploy frontend
cd beauty-parlour && firebase deploy --only hosting
```

## ⚠️ Troubleshooting

### Backend not responding?
1. Check: https://dashboard.render.com
2. Wait 1-2 minutes for startup
3. Check environment variables are set

### Frontend won't load?
1. Clear browser cache (Ctrl+Shift+Del)
2. Check: https://console.firebase.google.com
3. Verify API URL in network tab

### API returns errors?
1. Check error message
2. Verify JWT token is being sent
3. Check Render backend logs
